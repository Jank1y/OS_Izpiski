🔢Pretvorba dovoljenj NA VSAKEM KOLOKVIJU

VREDNOSTI: r=4, w=2, x=1
7 = rwx4+2+1
6 = rw-4+2+0
5 = r-x4+0+1
4 = r--4+0+0
3 = -wx0+2+1
2 = -w-0+2+0
1 = --x0+0+1
0 = ---0+0+0
POSEBNI BITI (4. cifra):
1xxxsticky bit → T/t na koncu (npr. 1770)
2xxxSGID bit
4xxxSUID bit
755 → rwxr-xr-x (lastnik vse, ostali r-x)
644 → rw-r--r-- (lastnik rw, ostali r)
664 → rw-rw-r--
421 → r---w---x
751 → rwxr-x--x
1770 → rwxrwx--T (sticky bit!)

drwxrwx--T → 1770 (d=imenik, T=sticky)
Sticky bit (T) na imeniku: uporabniki ne morejo brisati datotek drugih uporabnikov.

⚙️ BASH SKRIPTANJE

📜Bash skripta — template za kolokvij PROGRAMERSKA NALOGA

#!/bin/bash

# 1. PREVERI ARGUMENTE
if [ -z "$1" ]; then
  echo "Vhodni argument ni podan"
  exit 99
fi
USER1="$1"
LINK="${2}" # neobvezen 2. argument

# 2. USTVARI IMENIK (z napako)
mkdir -p /tmp/"$USER1"/datoteke && echo "Ustvarjen nov imenik" || { echo "Napaka med ustvarjanjem imenika"; exit 2; }

# 2b. ALI PREVERI ČE ŽE OBSTAJA
imenik="${1:-skupnaraba}" # privzeta vrednost
mkdir /home/"$imenik" || { echo "Imenik že obstaja"; exit 5; }

# 3. USTVARI SKUPINO
groupadd sodelovanje && echo "Ustvarjena nova skupina za skupno rabo" || echo "Skupina za skupno rabo že obstaja"

# 4. NASTAVI LASTNIŠTVO (rekurzivno)
chown -R "$USER1":"$USER1" /tmp/"$USER1"
chgrp sodelovanje /home/"$imenik"

# 5. NASTAVI DOVOLJENJA
chmod 1770 /home/"$imenik" # rwxrwx--T (sticky bit)
chmod 640 /home/hrast/veja.txt # lastnik rw, skupina r, ostali ---

# 6. MEHKA POVEZAVA (če je podan 2. argument)
[ -n "$LINK" ] && ln -s /tmp/"$USER1" /home/"$USER1"/"$LINK"

# 7. IZPIS /tmp
ls -lai /tmp

✅Primer rešitve — ustvarjanje userja (kolokvij 2023)

#!/bin/bash
sudo useradd veverica --home /home/hrast -m \
  || { echo "Nimaš pravic ali pa uporabnik že obstaja."; exit 42; }

sudo usermod -aG sudo veverica # dodaj v sudo skupino

echo $(id -u veverica) $(id -g veverica) # izpiši UID in GID

touch /home/hrast/veja.txt
sudo chown veverica:veverica /home/hrast/veja.txt
chmod 640 /home/hrast/veja.txt # lastnik rw-, skupina r--, ostali ---

# Dodaj pravice za branje/pisanje trenutnemu userju (brez spremembe lastništva):
setfacl -m u:$USER:rw /home/hrast/veja.txt
Za branje/pisanje brez spremembe lastništva se uporablja setfacl (Access Control List).
